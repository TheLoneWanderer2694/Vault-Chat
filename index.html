How to Host on GitHub Pages & Add to OBS

Follow these simple steps to deploy your personalized chat generator online for free and use it permanently in OBS.

Step 1: Save & Host on GitHub Pages

1. Create a new public repository on GitHub (e.g., twitch-chat-obs).
2. Save this entire HTML file as index.html and upload it to your repository.
3. Go to your repository settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main / root, and click Save. Your site will be live at https://yourusername.github.io/twitch-chat-obs/!

Step 2: Generate & Copy Your Custom OBS URL

Use the settings panel on the left to configure your fonts, colors, animations, and channel name. The OBS browser source link at the top will instantly encode all your settings into the URL hash parameters (no database required!). Copy that link.

Step 3: Add to OBS Studio

1. Open OBS Studio and select your Scene.
2. In the Sources box, click + and select Browser.
3. Paste your generated GitHub Pages URL into the URL field.
4. Set Width to 400 and Height to 800 (adjust as needed).
5. Click OK. Your fully customized, animated Twitch chat is now live on your stream!
